    What this monitor covers

    These checks detect availability failures and missing configuration. They do not sign in as a patient, book rides, process payments, validate real road routes, or verify message delivery. A healthy result applies only to the checks shown.

    Issues appear here after two failed checks and clear when a check passes. Acknowledging an issue records that it has been seen; it does not repair it. No code or production records are changed. AI recommendations require an API connection and human review.

    If no report arrives for more than 15 minutes, monitoring is marked stale. If the database or hosting platform is down, this monitor may also be unavailable.
